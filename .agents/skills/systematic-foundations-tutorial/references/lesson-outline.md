# Systematic lesson outline

Use this outline when restructuring an existing fundamentals article:

```text
Title and one-sentence promise
Concrete problem or failure
Prerequisites and running example
Model: objects, layers, states, or representation
Invariant, contract, or governing rule
Main process: before → transition → after
Implementation details and edge cases
Applications or composed scenarios
Alternatives, trade-offs, and boundaries
Worked example and observable evidence
Misconceptions
Understanding checks and exercises
Short summary or interview expression
Terminology card
```

Do not create a separate second-level heading for every method, synonym, field, or English word. Keep those details inside the stage that uses them.
