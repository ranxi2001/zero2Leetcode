## 选择数据结构的思路

先问“程序反复做什么操作”：

| 高频操作 | 首选结构 |
|----------|----------|
| 按下标访问 | 数组 |
| 中间节点插入/删除 | 链表 |
| 最近加入的先处理 | 栈 |
| 最早加入的先处理 | 队列 |
| 判断存在、按 key 查询 | 哈希表 |
| 反复取最小/最大 | 堆 |
| 层级关系 | 树 |
| 任意关系、路径、依赖 | 图 |
| 字符串前缀 | Trie |
| 动态判断是否连通 | 并查集 |
| 动态区间聚合 | 树状数组/线段树 |

## 先学会读“接口契约”

数据结构不是一段能跑通样例的代码，而是一个对外提供操作的抽象。读每一章时，先检查下面 8 项：

| 契约项 | 要回答的问题 | 示例 |
|---|---|---|
| 状态 | 结构内部保存什么不变量 | 堆顶是最小值 |
| 构造 | 如何创建空结构或带初值结构 | `deque()`、`FenwickTree(n)` |
| 查询 | 不改变结构的操作有哪些 | `peek`、`contains`、`range_sum` |
| 修改 | 会不会改变结构，是否原地 | `append`、`insert`、`union` |
| 空结构 | 没有元素时返回什么 | `None`、`False` 或抛异常 |
| 非法输入 | 越界、重复、类型错误如何处理 | `IndexError`、`ValueError` |
| 复杂度 | 最坏、平均还是均摊 | `append` 是均摊 O(1) |
| 别名与所有权 | 返回值是否共享原对象 | 切片新建列表，链表节点可能原地复用 |

### API 与实现不是一回事

- **接口 API**：调用者能做什么，以及结果和错误是什么。
- **实现 Implementation**：内部用数组、指针、哈希桶还是树。
- 同一接口可以有不同实现；同一实现也可以暴露不同接口。

例如“队列”是 FIFO 接口，Python 可以用 `deque` 实现，也可以用两个栈实现。面试回答不能只说类名，要先说语义。

### 复杂度的统一口径

- **最坏复杂度**：任何输入下都不超过的上界。
- **平均复杂度**：对输入分布或哈希假设取平均。
- **均摊复杂度**：一串操作的总成本平均到每次，例如动态数组扩容。
- 题目未说明时，默认空间复杂度包含结构本身和额外辅助空间，并写清口径。

### 空、重复和非法输入

不要把“题目保证输入合法”扩展成通用 API 保证。教程中的函数要明确：

```text
空结构：返回 None、空集合，还是抛 IndexError？
重复元素：保留、覆盖、计数，还是拒绝？
越界：静默截断、返回 False，还是抛异常？
输入是否被原地修改？
```

## 数据结构的统一观察法

### 1. 存储模型

先问数据在内存中怎样组织：

```text
连续槽位：数组、堆、矩阵
节点和指针：链表、树、Trie
槽位和哈希：HashMap、Set
关系和邻居：图
代表元和父指针：并查集
区间摘要：Fenwick、Segment Tree
```

存储模型直接影响：

- 能否按下标访问。
- 插入删除是否需要搬移。
- Cache 局部性。
- 指针和对象额外开销。
- 是否需要维护索引或元数据。

### 2. 不变量

**Invariant 直译**：不变量。

每次公开操作完成后必须保持的事实：

| 结构 | 典型不变量 |
|---|---|
| 动态数组 | 有效元素位于 `[0, size)`，没有空洞 |
| 链表 | 每条 next/prev 连接方向正确，head/tail 一致 |
| 栈 | pop 返回最近一次尚未弹出的元素 |
| 队列 | dequeue 返回最早尚未取出的元素 |
| 哈希表 | 相等 key 至多有一个有效 value |
| BST | 左小于根，右大于根（本模块重复策略需明确） |
| 堆 | 每个父节点不大于/不小于子节点 |
| Trie | 每条路径对应字符前缀，is_end 标记完整单词 |
| 并查集 | parent 链最终到达代表元 |
| Fenwick | 每个节点保存规定 lowbit 区间的聚合 |

写代码前写出不变量，调试时优先检查不变量。

### 3. 操作类型

- **访问 Access**：按下标、按 key、按代表元读取。
- **搜索 Search**：判断存在或寻找位置。
- **更新 Update**：修改值但不改变结构形状。
- **插入 Insert**：增加元素并维护结构。
- **删除 Delete**：移除元素并维护连接/索引。
- **遍历 Iterate**：按某种顺序访问所有元素。
- **聚合 Aggregate**：区间和、最值、连通分量等。

不同结构的优势，本质是对这些操作做了不同取舍。

### 4. 复杂度三问

看到一个 O(1) 要追问：

1. 是最坏、平均还是均摊？
2. 是否假设哈希均匀、树平衡或容量有界？
3. 是否把输出、复制和预处理成本排除在外？

例如：

- HashMap 平均 O(1) 依赖 hash 分布。
- BST 查找 O(h)，不平衡时 h 可为 n。
- 动态数组 append 均摊 O(1)，扩容瞬间 O(n)。
- `words_with_prefix` 至少要支付输出字符成本。

### 5. 选型决策树

```text
需要按下标访问？
  是 -> 数组
  否 -> 需要最近/最早顺序？
          最近 -> 栈
          最早 -> 队列
        需要 key 快速查找？
          是 -> HashMap/Set
        需要极值？
          是 -> Heap
        需要层级关系？
          是 -> Tree/Trie
        需要任意关系？
          是 -> Graph
        需要动态连通？
          是 -> Union-Find
        需要动态区间聚合？
          是 -> Fenwick/Segment Tree
```

### 6. 从题目条件反推接口

| 题目措辞 | 需要确认的接口 |
|---|---|
| “第 K 大” | `peek/pop` 极值、固定大小堆 |
| “是否出现过” | `contains`、key 是否可哈希 |
| “连续子数组” | 窗口边界、加入/移除状态 |
| “任意节点插入” | 是否已知节点引用，是否维护 tail |
| “前缀匹配” | Trie 的 `starts_with` 和输出 |
| “边不断加入” | Union-Find 的 `union/connected` |
| “区间修改后查询” | 闭区间约定、懒标记和单位元 |
| “ACM 输入” | token 语法、编号、空值和序列化 |

## 建议的每章学习产物

每学完一个结构，至少留下四样东西：

1. 一张结构布局图。
2. 一份最小实现。
3. 一张接口和复杂度表。
4. 一组覆盖空、单元素、重复、越界和极端规模的测试。

只有能写出这四样，才算真正掌握，而不是记住一道题。

## 模块级综合练习

1. 用 `DynamicArray` 实现栈，再用两个栈实现队列。
2. 用邻接表和 Union-Find 分别处理无向图连通性。
3. 用 Heap 和排序分别求 Top K，比较复杂度和常数。
4. 用 Trie 实现前缀计数与自动补全。
5. 用 Fenwick 和线段树分别实现动态区间和。
6. 设计统一的 ACM 序列化器，把链表、树和图转回文本。

## 复习标准

每个章节都应能回答：这个结构维护什么不变量？最小接口是什么？空值、重复值和非法输入怎样处理？复杂度依赖哪些前提？最后用一个最小测试证明接口没有被边界条件破坏。

## 面试前快速复盘

按下面顺序自问：

```text
我能画出结构吗？
我能写出最小接口吗？
我知道空和重复怎么处理吗？
我能说出复杂度的前提吗？
我能指出一个不适用场景吗？
我能用一个边界测试证明它吗？
```

如果只能背出“某操作 O(1)”，说明还没有掌握接口契约。
