    38|**难度** ：入门
    39|**考点** ：计算机网络
    40|**解释** ：隧道技术把整个 IPv6 报文当作载荷封装进 IPv4 报文头里，中间的纯 IPv4 网络只看外层 IPv4 头正常转发，到达隧道出口再拆封还原成 IPv6 包，这正是"穿越 IPv4 网络"的定义，故选 D。A 双协议栈是让同一台设备同时跑 IPv6 和 IPv4 两套协议栈，解决的是"设备能不能同时说两种话"，并不能让 IPv6 报文通过只认 IPv4 的中间网络。B 手动配置只是隧道端点地址的一种配置方式，属于隧道技术的子项而非并列的技术名称。C NAT-PT 做的是 IPv6 地址与 IPv4 地址之间的协议转换，让 IPv6 主机去访问 IPv4 主机，报文在转换后就不再是 IPv6 包了，属于"翻译"而非"穿越"。

   191|这是一道靠换枚举顺序把排列计数拆成连乘的计数题：难点不在算式，而在找到一种插入顺序，让每一步的合法位置数只与已经站好的人有关。
   192|### 算法实现
   193|直接枚举排列是  种， 到  时完全不可行，必须改成"一个一个往队伍里插，每步的选择数连乘"。
   194|插入顺序是分水岭。从矮到高插入时新来的人最高，前驱后继两侧都得检查；从高到矮插入，轮到  时在场的  全都满足 ，于是后继约束
   195|对每个在场元素都自动成立，把  插进去只可能破坏它与前驱那一侧。
   196|每步于是只剩一条要验： 插在  后面需要 ，即 ；插到队首时没有前驱，恒合法。降序排序后，第 （从  起）个元素的合法位置数为
   197|答案即 ，边乘边对  取模。样例降序为 ，四步各有  个位置，其中  被两个  挡住只能打头。
   198|连乘不重不漏靠一组双射：把合法排列里的人按身高从大到小读出，每人被读到时在剩余序列里的位置唯一确定了那一步的选择；反过来任一串选择也只还原出一个排列。身高相同的同学学号不同，按降序排好的下标区分，不会被并成一种。
   199|数  不必每次重扫。降序下 ，不合法的  恰好是一段前缀，且  越往后越矮，这段前缀只增不减，指针单调右移，全程 。
   200|### 时空复杂度分析
   201|**时间复杂度** ：。瓶颈在排序，双指针的每个下标至多被越过一次、只有 ；而合法位置数要靠有序性才能用指针数出来，排序省不掉。 时约  次比较。
   202|**空间复杂度** ：，存身高数组。
   203|**Java**
   204|
   205|```
   206|// 合影 - 排序 + 双指针计数
   207|import java.io.BufferedReader;
   208|import java.io.InputStreamReader;
   209|import java.io.StreamTokenizer;
   210|import java.util.Arrays;
   211|
   212|public class Main {
   213|    static final long MOD = 998244353L;
   214|
   215|    // 统计满足相邻约束的排列数：把身高从大到小逐个插入序列，累乘每一步的可放位置数
   216|    static long countPlans(int n, int d, int[] a) {
   217|        // 从大到小插入：轮到 x 时已放入的同学都不比 x 矮，
   218|        // 于是"x 的后继 >= x - D"必然成立，只剩"x 的前驱 y 满足 y <= x + D"这一条要管
   219|        Arrays.sort(a);
   220|
   221|        long ans = 1;
   222|        int j = n - 1;  // 数组是升序，从尾部往前扫等价于降序；a(j, n-1] 是高得放不下当前身高的那一段
   223|        for (int i = n - 1; i >= 0; i--) {
   224|            long limit = (long) a[i] + d;
   225|            // 把前驱过高（y > x + D）的位置全部剔除，剩下 j - i 个合法插入点
   226|            while (j > i && a[j] > limit) {
   227|                j--;
   228|            }
   229|            // 再加 1 是"放到整个队伍最前面"——没有前驱，恒合法
   230|            ans = ans * (j - i + 1) % MOD;
   231|        }
   232|        return ans;
   233|    }
   234|
   235|    public static void main(String[] args) throws Exception {
   236|        // 用 StreamTokenizer 按空白切词读入，N 到 2e5 时比逐行切分快得多
   237|        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
   238|        in.nextToken();
   239|        int n = (int) in.nval;
   240|        in.nextToken();
   241|        int d = (int) in.nval;
   242|
   243|        int[] a = new int[n];
   244|        for (int i = 0; i < n; i++) {
   245|            in.nextToken();
   246|            a[i] = (int) in.nval;
   247|        }
   248|
   249|        System.out.println(countPlans(n, d, a));
   250|    }
   251|}

   255|## 题目描述

   279|**样例解释**
   280|可以将金块分割为  这四段。此时四段的总价值分别为 。这四个数中的最大值是 ，最小值是 ，差值为 。没有比  更小的差值。
   281|## 题解：前缀和 + 枚举中间切点 + 双指针
   282|### 题目问题拆解
   283|把长度为  的数组切三刀分成四段非空的连续区间，要让这四段和的极差最小。
   284|这是一道靠固定一刀把问题劈成两个独立子问题的题：难点在于看出中间那一刀定下来之后，左右两半的切法互不影响，从而不必三重枚举。
   285|### 算法实现
   286|三刀的位置组合有  种， 到  时枚举不动。先记前缀和
   287|一段  的价值即 ，任何一种切法都能  算出四段。
   288|突破口是先固定中间那一刀 ，把金条劈成  与  两半。左半两段之和恒为 、右半恒为 ，都是与另一半无关的定值，所以左右各自取最平衡即可，不必联动。
   289|再看单独一半怎么切最平衡。左半两段是  与 ，两者之和固定，这意味着"压低最大值"和"抬高最小值"是同一个动作，即让  尽量贴近 。于是左刀取第一个满足  的位置，右刀同理取第一个满足  的位置。
   290|这里有个必须留的后手：最贴近目标值的位置可能落在目标值两侧，指针停下的那一格与它左边一格谁更平衡取决于跨过去多少，两个都要试，左右组合共  种各算一次极差。只取跨过目标值的那一格会漏解，例如左半为  时指针会停在  那侧，而切在它左边才是唯一的切法。
   291|指针能单调右移是因为 ， 严格递增，两个目标值  与  都随  单增，故  与  只进不退。
   292|### 时空复杂度分析
   293|**时间复杂度** ：。前缀和一趟 ；枚举中间刀 ，两个指针在整个枚举过程中各只前进至多  步、均摊 ，每个  固定后只试  种组合。若改用二分找平衡点则是 ，单调性让这个  省掉了，瓶颈只剩读入。
   294|**空间复杂度** ：，存前缀和数组。
   295|**Java**
   296|
   297|```
   298|// 金条切割 - 前缀和 + 枚举中间切点 + 双指针
   299|import java.io.BufferedReader;
   300|import java.io.InputStreamReader;
   301|import java.io.StreamTokenizer;
   302|
   303|public class Main {
   304|    // 求四段价值中最大值与最小值的最小差值
   305|    static long solve(int n, long[] a) {
   306|        // 不足 4 节切不出四段非空，题面约束下不会出现，兜一层防越界
   307|        if (n < 4) {
   308|            return 0;
   309|        }
   310|
   311|        // s[i] 是前 i 节小金块的价值和；A_i >= 1 保证 s 严格递增，后面才能用单调指针
   312|        // n 到 1e5、A_i 到 1e9，总和可达 1e14，必须用 long
   313|        long[] s = new long[n + 1];
   314|        for (int i = 0; i < n; i++) {
   315|            s[i + 1] = s[i] + a[i];
   316|        }
   317|
   318|        // best 用 -1 当哨兵，表示还没取到过任何一种切法
   319|        long best = -1;
   320|        // i 追踪左半的平衡点，k 追踪右半的平衡点；两个目标值都随 j 单增，所以指针只往右走
   321|        int i = 1;
   322|        int k = 1;
   323|        // 枚举中间那一刀 j：左半 [1..j] 里再切一刀，右半 [j+1..n] 里再切一刀
   324|        for (int j = 2; j <= n - 2; j++) {
   325|            // 左半两段是 s[i] 与 s[j]-s[i]，两者之和恒为 s[j]，所以"压低最大值"和"抬高最小值"
   326|            // 是同一个选择，把 i 推到第一个满足 2*s[i] >= s[j] 的位置即最平衡
   327|            while (i < j && 2 * s[i] < s[j]) {
   328|                i++;
   329|            }
   330|            // 右半两段之和恒为 s[n]-s[j]，同理推到第一个满足 2*s[k] >= s[n]+s[j] 的位置
   331|            while (k < n && 2 * s[k] < s[n] + s[j]) {
   332|                k++;
   333|            }
   334|
   335|            // 平衡点跨过目标值，它和它左边一格都要试：谁更平衡取决于跨过去多少
   336|            for (int li = i - 1; li <= i; li++) {
   337|                if (li < 1 || li > j - 1) {
   338|                    continue;
   339|                }
   340|                long p1 = s[li];
   341|                long p2 = s[j] - s[li];
   342|                for (int ri = k - 1; ri <= k; ri++) {
   343|                    if (ri < j + 1 || ri > n - 1) {
   344|                        continue;
   345|                    }
   346|                    long p3 = s[ri] - s[j];
   347|                    long p4 = s[n] - s[ri];
   348|                    long hi = Math.max(Math.max(p1, p2), Math.max(p3, p4));
   349|                    long lo = Math.min(Math.min(p1, p2), Math.min(p3, p4));
   350|                    if (best < 0 || hi - lo < best) {
   351|                        best = hi - lo;
   352|                    }
   353|                }
   354|            }
   355|        }
   356|        return best;
   357|    }
   358|
   359|    public static void main(String[] args) throws Exception {
   360|        // N 到 1e5，用 StreamTokenizer 按空白切词读入，比逐行分割快
   361|        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
   362|        in.nextToken();
   363|        int n = (int) in.nval;
   364|        long[] a = new long[n];
   365|        for (int i = 0; i < n; i++) {
   366|            in.nextToken();
   367|            a[i] = (long) in.nval;
   368|        }
   369|        System.out.println(solve(n, a));
   370|    }
   371|}
   372|```
