## 选择题（可恢复 5 道）

**1、设 $P(A)=0.3$，$P(B)=0.5$，$P(B\mid A)=0.6$，则 $P(A\mid B)$ 的值为？**

A. 0.36

B. 0.5

C. 0.3

D. 0.6

**答案**：A。

**解析**：先求交事件概率 $P(A\cap B)=P(A)P(B\mid A)=0.18$，再计算 $P(A\mid B)=0.18/0.5=0.36$。两个方向的条件概率不能直接交换。

**2、神经网络使用线性激活函数时，多个隐藏层的效果等价于？**

A. 多个线性层

B. 一个线性变换

C. 没有隐藏层

D. 一个非线性变换

**答案**：B。

**解析**：连续两层可合并为 $W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$。无论堆叠多少层，都不会产生非线性表达能力。严格地说，含偏置时是一次仿射变换；选项 B 使用的是神经网络中常见的宽泛说法。“没有隐藏层”可用于描述合并后的网络结构，但 B 更准确地指出了其等价的函数形式。

**3、用户—物品评分矩阵的大部分元素为 $0$，以下哪种存储方式最节省空间？**

A. 二维数组

B. 三元组列表（COO）

C. 连续内存块

D. 稠密矩阵存储

**答案**：B。

**解析**：COO 只保存非零元素的行号、列号和值，所需空间随非零元素数量增长。二维数组与稠密矩阵仍为全部位置分配空间；“连续内存块”只描述布局，不代表省略零元素。

**4、关于词元化在数据预处理中的作用，正确的是？**

A. 词元化直接将文本转化为固定长度的向量

B. 字节对编码（BPE）是一种常见的字词分割算法，用于平衡词表大小与未登录词问题

C. 词元化后，所有语言的每个字符都会被编码为一个单独词元

D. 词元化过程会丢失所有标点符号信息

**答案**：B。

**解析**：BPE 逐步合并高频相邻单元，常见片段可整体编码，少见词则拆成子词。词元化主要产生词元及其 ID 序列，嵌入向量由后续嵌入层产生；一个词元不必对应一个字符，标点通常也会保留。

**5、在数据并行（DP）策略中，关于模型副本和数据分配的描述，正确的是？**

A. 每个 GPU 存储完整的模型副本，处理不同的数据批次

B. 每个 GPU 存储模型的一部分层，处理不同的数据批次

C. 每个 GPU 存储完整的模型副本，处理相同的数据批次

D. 每个 GPU 存储模型的不同层，处理相同的数据

**答案**：A。

**解析**：标准数据并行复制完整模型，让各设备处理不同的数据分片，再同步梯度以保持参数一致。把模型按层拆分属于模型并行的范畴。这里讨论标准 DP，不把参数分片等混合优化策略混入定义。

## 第 1 题：激活重计算

### 题目描述

模型有 $N$ 层，编号为 $1$ 至 $N$，依次执行前向传播。给定两个长度为 $N$ 的正整数数组：

- `forward_time[i]`：第 $i+1$ 层的前向计算耗时。
- `memory[i]`：在第 $i+1$ 层保存激活值所需的额外显存。

第 $0$ 层为输入层，其激活值常驻显存，是免费的起始检查点。第 $N$ 层为终点，同样不需要额外保存激活值。可以在中间层 $1\le c\le N-1$ 设置检查点，每个检查点消耗 `memory[c-1]` 显存，总开销不得超过预算 $M$（即输入中的 `MaxMem`）。

设相邻检查点为 $c,d$，中间没有其他检查点。第 $k$ 层需要重算 $d-k$ 次，因此这段的重计算代价为：

$$
C(c,d)=\sum_{k=c+1}^{d-1} f_k(d-k),\qquad f_k=\text{forward\_time}[k-1].
$$

相邻层间的代价为零。求所有相邻检查点区间的代价之和的最小值，边界检查点 $0,N$ 必须包含在内。

### 输入格式

- 第一行两个整数 $N,M$，满足 $1\le N\le100$、$0\le M\le1000$。
- 第二行 $N$ 个整数 $f_i$，满足 $1\le f_i\le1000$。
- 第三行 $N$ 个整数 $m_i$，满足 $1\le m_i\le100$。

### 输出格式

输出一个整数，表示最小总重计算代价。

### 样例 1

**输入**

```
4 5
10 20 30 40
3 4 2 6
```

**输出**

```
20
```

**说明**：在第 $1,3$ 层保存检查点，共使用 $3+2=5$ 显存。只有区间 $(1,3)$ 产生代价，即第 $2$ 层重算一次，耗时为 $20$。

### 样例 2

**输入**

```
3 0
5 5 5
1 1 1
```

**输出**

```
15
```

**说明**：预算为零，只能使用边界检查点。第 $1$ 层重算两次，第 $2$ 层重算一次，总耗时为 $15$。

### 思路分析

**第一步：把区间代价化为常数时间查询。**

直接枚举所有检查点集合需要指数级时间。即使采用动态规划，如果每次转移都扫描区间，也会增加一层循环。定义两个前缀和：

$$
S_1[x]=\sum_{k=1}^{x}f_k,\qquad S_2[x]=\sum_{k=1}^{x}k f_k.
$$

展开 $f_k(d-k)$，得到：

$$
C(c,d)=d\bigl(S_1[d-1]-S_1[c]\bigr)-\bigl(S_2[d-1]-S_2[c]\bigr).
$$

例如样例 1 不设置任何中间检查点时，区间 $(0,4)$ 的代价为 $10\times3+20\times2+30=100$。

**第二步：状态必须同时记录位置与显存。**

设 `dp[d][used]` 表示最后一个检查点位于第 `d` 层、已使用恰好 `used` 显存时，到该位置的最小代价。初始化 `dp[0][0]=0`，其余为不可达。

枚举上一个检查点 `c < d`，在二者之间不再设置检查点。设新增显存为 $w_d$：中间层取 $m_d$，终点则取 $0$。转移为：

$$
dp[d][j+w_d]=\min\bigl(dp[d][j+w_d],dp[c][j]+C(c,d)\bigr).
$$

只有 $j+w_d\le M$ 时才能转移。最终答案是 `min(dp[N])`，不要求花光预算。

**第三步：说明转移为什么完整。**

任意合法方案在到达 `d` 前都有唯一的前驱检查点 `c`。删除最后一段后，剩余部分正是一个相同定义的子问题；若该前缀不是最优，可以替换为更优前缀而不改变末段和显存用量。枚举所有 `c` 与 `j` 因此既不遗漏合法方案，也不会引入非法方案。

**实现细节**：终点既不扣显存，也不重算自身，输入最后一项耗时和显存仍需正常读入。`N=1` 时两端相邻，答案自然为零。下面使用标准库实现，不依赖 NumPy，也不对未披露的评测时限作通过保证。

### 题解代码

```python
import sys


def min_recompute_cost(n, budget, times, memory):
    prefix = [0] * (n + 1)
    weighted = [0] * (n + 1)
    for i in range(1, n + 1):
        prefix[i] = prefix[i - 1] + times[i - 1]
        weighted[i] = weighted[i - 1] + i * times[i - 1]

    inf = 10**30
    dp = [[inf] * (budget + 1) for _ in range(n + 1)]
    dp[0][0] = 0
    for d in range(1, n + 1):
        need = memory[d - 1] if d < n else 0
        if need > budget:
            continue
        row = dp[d]
        for c in range(d):
            cost = d * (prefix[d - 1] - prefix[c])
            cost -= weighted[d - 1] - weighted[c]
            prev = dp[c]
            for used in range(budget - need + 1):
                candidate = prev[used] + cost
                if candidate < row[used + need]:
                    row[used + need] = candidate
    return min(dp[n])


def solve():
    input = sys.stdin.readline
    n, budget = map(int, input().split())
    times = list(map(int, input().split()))
    memory = list(map(int, input().split()))
    print(min_recompute_cost(n, budget, times, memory))


if __name__ == "__main__":
    solve()
```

### 复杂度分析

**时间复杂度**：$O(N^2(M+1))$，枚举两个检查点位置与已用显存；前缀和使每段代价只需常数时间。

**空间复杂度**：$O(N(M+1))$，用于保存动态规划表。使用 $M+1$ 表述也覆盖预算为零的情况。

## 第 2 题：训练成本优化

### 题目描述

将 `grad_times` 中的 $n$ 个梯度更新任务分配到 $k$ 张 NPU 卡，每个任务必须且只能分配一次，任务不可拆分。设第 $i$ 张卡分到的任务总耗时为 $s_i$，所有卡中的最大总耗时为 $T$。

优化目标有严格的先后顺序：

1. 先使 $T=\max_i s_i$ 最小。
2. 在第一目标最优的所有方案中，使总训练成本最小。

设基础学习率为 $b$（`base_lr`），衰减系数为 $r$（`decay_rate`），每张卡的学习率和成本为：

$$
\mathrm{lr}_i=b\cdot r^{T-s_i},\qquad \mathrm{cost}_i=s_i\cdot\mathrm{lr}_i.
$$

总成本为所有卡成本的和。

### 输入格式

输入一行，四个字段用分号分隔：

```
梯度耗时列表;NPU数量;基础学习率;衰减系数
```

- 耗时列表内部使用逗号分隔，$1\le n\le12$，$0\le t_i\le1000$。
- $1\le k\le n$。
- $0<b\le1$，$0<r<1$，二者的小数位数均不超过四位。

### 输出格式

输出 `最小最大总耗时;最小总训练成本`，前者为整数，后者保留四位小数。

> 题面输出格式说明中还出现了 `6;1.6590`，它只是格式示意，不是下方样例 1 的答案；应以完整样例输入、输出为准。

### 样例 1

**输入**

```
4,3,2,3,5,2,1;3;0.1;0.9
```

**输出**

```
7;1.9400
```

**说明**：总耗时为 $20$，分给三张卡时最大值至少为 $7$。划分为 $\{4,3\}$、$\{5,2\}$、$\{3,2,1\}$ 可得到负载 $7,7,6$，成本为 $0.7+0.7+0.54=1.94$。

### 样例 2

**输入**

```
5;1;0.1;0.9
```

**输出**

```
5;0.5000
```

**说明**：只有一张卡，指数为零，成本为 $5\times0.1=0.5$。

### 思路分析

**第一步：用位掩码表示任务集合。**

直接为每个任务枚举卡号需要考虑 $k^n$ 种分配。由于 $n\le12$，可以用整数 `mask` 表示一组任务，第 `i` 位为一就表示包含任务 `i`。预处理 `subset_sum[mask]`，每次移除最低位即可由一个更小的集合得到当前集合的总耗时。

**第二步：先求最优最大耗时。**

设 $G(j,S)$ 表示把集合 $S$ 分给 $j$ 张卡时，最小可能的最大单卡耗时。选出交给其中一张卡的非空子集 $A$，其余交给另外 $j-1$ 张卡：

$$
G(j,S)=\min_{\varnothing\ne A\subseteq S}\max\bigl(G(j-1,S\setminus A),\mathrm{sum}[A]\bigr).
$$

初始状态 $G(0,\varnothing)=0$，其他零卡状态不可达。得到 $T=G(k,\mathrm{full})$ 后，再开始第二阶段。

**第三步：固定 $T$，优化总成本。**

把统一因子 $b$ 提到最后，定义单卡贡献 $h(s)=s r^{T-s}$。设 $F(j,S)$ 表示固定上限 $T$ 后的最小贡献和：

$$
F(j,S)=\min_{A\subseteq S,\ A\ne\varnothing,\ \mathrm{sum}[A]\le T}
\bigl(F(j-1,S\setminus A)+h(\mathrm{sum}[A])\bigr).
$$

最后输出 $bF(k,\mathrm{full})$。不能提前按某个临时最大值计算成本，因为最大值变化会同时影响此前所有卡的学习率。

**第四步：利用卡的对称性减少枚举。**

对于任意一个集合划分，恰好有一个分组包含当前集合的最低位任务。强制本轮选出的组包含该任务，相当于给无标签分组规定一个唯一顺序，并不会漏解。其余元素从 `rest` 的所有子集中选择，通过 `(sub - 1) & rest` 遍历。

状态至少需要 `j` 个任务才能形成 `j` 个非空组。恰好剩一张卡时整组直接分给它，可以提前返回。代码采用两遍相同的滚动 DP 骨架，第一遍聚合最大值，第二遍聚合成本和。

**为什么可以让每张卡都拿到任务？** 若允许空组且存在空卡，由于 $k\le n$，可以拆分一个多任务组来填充空卡。负载最大值不会增加；在已经达到全局最优 $T$ 的方案上，也不可能进一步降低 $T$。固定此 $T$，对 $a,b\ge0$ 有：

$$
a r^{T-a}+b r^{T-b}\le(a+b)r^{T-a-b}.
$$

这是因为 $0<r<1$，左右两项各自都不大于使用共同指数 $T-a-b$ 的对应项。因此拆分不会增加成本，始终存在使用恰好 $k$ 个非空组的最优方案。耗时为零的任务也按普通任务计入集合。

### 题解代码

```python
import sys


def optimize_training(times, k, base_lr, decay):
    n = len(times)
    size = 1 << n
    full = size - 1
    subset_sum = [0] * size
    count = [0] * size
    for mask in range(1, size):
        low = mask & -mask
        prev = mask ^ low
        subset_sum[mask] = subset_sum[prev] + times[low.bit_length() - 1]
        count[mask] = count[prev] + 1

    inf = float("inf")

    def partition(limit=None, cost=None):
        dp = [inf] * size
        dp[0] = 0.0 if cost is not None else 0
        for groups in range(1, k + 1):
            current = [inf] * size
            for mask in range(1, size):
                if count[mask] < groups or count[mask] > n - k + groups:
                    continue
                if groups == 1:
                    load = subset_sum[mask]
                    if cost is None:
                        current[mask] = load
                    elif load <= limit:
                        current[mask] = cost[mask]
                    continue
                low = mask & -mask
                rest = mask ^ low
                sub = rest
                best = inf
                while True:
                    chosen = sub | low
                    prev = dp[mask ^ chosen]
                    load = subset_sum[chosen]
                    if prev != inf:
                        if cost is None:
                            candidate = max(prev, load)
                            if candidate < best:
                                best = candidate
                        elif load <= limit:
                            candidate = prev + cost[chosen]
                            if candidate < best:
                                best = candidate
                    if sub == 0:
                        break
                    sub = (sub - 1) & rest
                current[mask] = best
            dp = current
        return dp[full]

    best_time = partition()
    cost = [0.0] * size
    for mask, load in enumerate(subset_sum):
        if load <= best_time:
            cost[mask] = load * decay ** (best_time - load)
    best_cost = partition(best_time, cost) * base_lr
    return best_time, best_cost


def solve():
    input = sys.stdin.readline
    tasks, cards, rate, decay = input().strip().split(";")
    times = list(map(int, tasks.split(",")))
    best_time, best_cost = optimize_training(
        times, int(cards), float(rate), float(decay)
    )
    print(f"{best_time};{best_cost:.4f}")


if __name__ == "__main__":
    solve()
```

### 复杂度分析

**时间复杂度**：$O(k3^n)$，每一层枚举集合及其子集，两阶段只增加常数倍；子集贡献表预处理不改变主项。这里按题目有界耗时下的浮点幂运算计费。

**空间复杂度**：$O(2^n)$，保存子集和、任务数、成本表及滚动 DP 数组。

## 小结

- 条件概率的方向、线性与仿射的区别、词元化与嵌入的区别，是选择题中容易混淆的边界。
- 激活重计算的关键不是单独给每层定价，而是给相邻检查点形成的区间定价，再把显存预算放进状态。
- 训练成本优化必须按优先级分两阶段求解；固定第一目标的最优值之后，第二目标才具备独立可加的单组代价。
- 无标签分组通过最低位锚点消除对称重复，零耗时任务、零显存预算与终点免费等边界都不能遗漏。
