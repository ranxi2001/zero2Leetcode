## 第 1 题：YANG 模型配置精简器

### 题目描述

给定一段 YANG 格式文本，删除以 `description`、`default`、`mandatory` 为关键字的语句，同时保持注释和换行结构不变。

- 删除范围从关键字首字符到其后的语句结束符 `;`，包含两端。删除范围内只保留换行符 `\n`，其余字符全部删除；关键字前的缩进不属于删除范围。
- `//` 至行尾是行注释，`/*` 至 `*/` 是块注释。注释原样保留，其中的目标关键字不能触发删除。
- 关键字之前必须是行首、空格、制表符、`{` 或 `;`；之后必须是空格、制表符、换行或双引号。`mydescription`、`description_ext` 等普通标识符不能删除。
- 输入基本合法，`;` 总是有效的语句结束符。待删除语句内部不会出现注释，引号内也不会再次出现目标关键字，无须实现完整的 YANG 语法解析器。

### 输入描述

读取至文件结束，得到长度为 $L$ 的字符串，$1\le L\le2\times10^5$。

### 输出描述

输出清洗后的字符串，保留删除区间外的全部字符，以及删除区间内的换行。

### 样例

**输入**

```
leaf x {
  description "x";
}
```

**输出**

```
leaf x {
  
}
```

第二行精确保留两个空格。这些空格属于答案数据，不是 Markdown 排版空白，不能删除。

### 思路分析

**第一步：先保护注释。** 单纯全局替换关键字会误删注释。指针从左向右扫描，遇到行注释或块注释就整段复制并跳过，不检查其中的关键字。

**第二步：验证原字符串中的边界。** 只有关键字字面量和前后边界同时满足，才能开始删除。边界应检查原始文本，而不是已经输出的结果，否则删除前面的语句可能改变后续识别结果。

**第三步：删除字符但保留换行。** 找到有效关键字后，定位后面的第一个分号，把这段中的换行复制到答案，再跳到分号之后。由于题面保证分号有效、待删语句不含注释，无须额外处理嵌套。未匹配时复制当前字符。

循环开始时，指针之前的文本已经按规则处理完毕；每轮处理一个完整注释、一个完整删除区间或一个普通字符。因此既不会漏掉字符，也不会重新扫描已经处理的范围。

### 题解代码

```python
import sys


def clean(text):
    keywords = ("description", "default", "mandatory")
    result = []
    i = 0
    n = len(text)
    while i < n:
        if text.startswith("//", i):
            end = text.find("\n", i)
            end = n if end < 0 else end
            result.append(text[i:end])
            i = end
            continue
        if text.startswith("/*", i):
            end = text.find("*/", i + 2)
            end = n if end < 0 else end + 2
            result.append(text[i:end])
            i = end
            continue
        matched = False
        if i == 0 or text[i - 1] in " \t\n{;":
            for keyword in keywords:
                end = i + len(keyword)
                if (text.startswith(keyword, i) and end < n
                        and text[end] in ' \t\n"'):
                    end = text.find(";", end) + 1
                    result.append("\n" * text.count("\n", i, end))
                    i = end
                    matched = True
                    break
        if not matched:
            result.append(text[i])
            i += 1
    return "".join(result)


def solve():
    sys.stdout.write(clean(sys.stdin.read()))


if __name__ == "__main__":
    solve()
```

### 复杂度分析

**时间复杂度**：$O(L)$。指针单调向右，每段注释或删除范围只扫描常数次。

**空间复杂度**：$O(L)$，用于保存输入与输出。

## 第 2 题：王子拯救公主

### 题目描述

在一个迷宫中，王子从 `S` 出发寻找公主 `P`，每步只能向上下左右移动一格。地图中的 `.` 是空地，`#` 是墙，`M` 是怪物，`W` 是宝剑；地图外不能通行。

没有宝剑时，不能进入怪物格，也不能进入怪物上下左右距离为一格的位置。拿到宝剑后，可以进入怪物周围的格子，也可以进入怪物格并杀死当前位置的怪物，不能穿墙。

有两个特殊规则：宝剑即使位于怪物旁边，也允许直接进入该格并拾取；起点即使位于怪物旁边，也允许从起点行动一次，但下一步仍须满足通行条件。

求到达公主位置的最少步数，无法到达时输出 `-1`。

### 输入描述

第一行两个整数 $n,m$，$1\le n,m\le100$。接下来 $n$ 行，每行 $m$ 个字符。保证恰有一个 `S` 和一个 `P`。

### 输出描述

输出最少步数，或 `-1`。

### 样例 1

**输入**

```
4 5
S....
.M...
....M
...MP
```

**输出**

```
-1
```

### 样例 2

**输入**

```
4 5
S....
W....
...M.
....P
```

**输出**

```
7
```

先向下拿剑，再经过第三行接近公主，可以用七步到达。

### 样例 3

**输入**

```
1 4
S..P
```

**输出**

```
3
```

### 思路分析

**第一步：预处理危险格。** 对每个怪物标记其自身和四邻格。没有剑时，除了宝剑格，这些格子都不能进入。

**第二步：位置不是完整状态。** 同一个位置，持剑与否会影响之后能走的边。如果只记录一次访问，先以无剑状态到达就可能阻止之后携剑返回。使用 $(x,y,s)$ 表示状态，$s\in\{0,1\}$ 表示是否持剑。

**第三步：在两层图上 BFS。** 移动到宝剑格时先将持剑标记设为真，再检查危险区限制，正好实现“危险区内也可以捡剑”的例外。起点直接入队，不对起点做危险检查；后续目的格照常检查。

拿剑后不会丢失，所有非墙格都可以通行，因此无需记录哪些怪物已被杀死。每条边代价都是一步，BFS 第一次到达公主时就是最短距离。

### 题解代码

```python
import sys
from collections import deque


def shortest_path(grid):
    n, m = len(grid), len(grid[0])
    directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
    danger = [[False] * m for _ in range(n)]
    start = None
    for x in range(n):
        for y in range(m):
            if grid[x][y] == "S":
                start = (x, y)
            elif grid[x][y] == "M":
                danger[x][y] = True
                for dx, dy in directions:
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < n and 0 <= ny < m:
                        danger[nx][ny] = True
    dist = [[[-1, -1] for _ in range(m)] for _ in range(n)]
    x, y = start
    dist[x][y][0] = 0
    queue = deque([(x, y, 0)])
    while queue:
        x, y, sword = queue.popleft()
        if grid[x][y] == "P":
            return dist[x][y][sword]
        for dx, dy in directions:
            nx, ny = x + dx, y + dy
            if not (0 <= nx < n and 0 <= ny < m):
                continue
            cell = grid[nx][ny]
            if cell == "#":
                continue
            next_sword = int(sword or cell == "W")
            if not next_sword and danger[nx][ny]:
                continue
            if dist[nx][ny][next_sword] != -1:
                continue
            dist[nx][ny][next_sword] = dist[x][y][sword] + 1
            queue.append((nx, ny, next_sword))
    return -1


def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    grid = [input().strip() for _ in range(n)]
    print(shortest_path(grid))


if __name__ == "__main__":
    solve()
```

### 复杂度分析

**时间复杂度**：$O(nm)$，每个格子至多对应两个状态，每个状态检查四条边。

**空间复杂度**：$O(nm)$，用于危险标记、距离和队列。

## 第 3 题：武林高手

### 题目描述

一座神秘岛上有 $N$ 个事件，第 $i$ 个事件发生在闭区间 $[S_i,E_i]$，奖励为 $V_i$。一次停留区间为 $[s,e]$，只有完整覆盖事件，即 $s\le S_i\le E_i\le e$，才能得到对应奖励；同时需要支付 $(e-s)M$ 的功力消耗。

最多可以进出岛两次，也可以一次或不进入。两次停留必须严格分离：第二次进入时刻大于第一次退出时刻。每个选中的停留区间净收益必须严格大于零。

进入、退出时刻只能从所有事件的开始、结束时间集合中选择，允许同一时刻进入并退出。求最大总收益及对应方案；收益相同时，选择按开始时间排序后的区间数组中字典序最小者。

### 输入描述

第一行两个整数 $N,M$，$1\le N\le10^4$，$0\le M\le10^9$。

接下来 $N$ 行，每行三个整数 $S_i,E_i,V_i$，满足 $1\le S_i\le E_i\le10^9$，$0\le V_i\le10^9$。

### 输出描述

第一行输出最大总收益。随后每个区间单独输出一行，格式为 `进入时刻,退出时刻`。不进入时第一行输出 `0`，第二行输出 `NA`。

### 样例 1

**输入**

```
3 5
1 3 4
1 2 2
4 6 2
```

**输出**

```
0
NA
```

### 样例 2

**输入**

```
5 2
1 3 4
1 2 6
4 6 2
10 11 7
100 101 7
```

**输出**

```
11
1,3
10,11
```

第一段收益为 $4+6-(3-1)\times2=6$，第二段收益为 $7-(11-10)\times2=5$。选择 `[100,101]` 也有五点收益，但 `[10,11]` 的字典序更小。

### 样例 3

**输入**

```
3 2
1 3 4
1 2 6
5 10 1
```

**输出**

```
6
1,3
```

### 思路分析

**第一步：拆开单段收益。** 设所有不同端点排序后为 $t$。直接枚举两个停留区间不可行，即使只枚举单段也有平方级候选。固定退出时刻 $e$ 时，收益可以改写为：

$$
f(s,e)=\left(sM+\sum_{E_i\le e,\ S_i\ge s}V_i\right)-eM.
$$

括号外与进入时刻无关。为每个候选进入时刻维护括号内的值，初值为 $sM$。按事件结束时间扫描，每遇到事件 $(S_i,E_i,V_i)$，所有不晚于 $S_i$ 的进入时刻都增加 $V_i$，即一次前缀加。查询不晚于当前退出时刻的候选最大值，再减去 $eM$，就得到以此时刻退出的最优单段。

**第二步：用线段树维护最大值和端点。** 节点记录最大值、取得最大值的进入下标以及懒加标记。值相同时选择更小进入下标，保证固定退出时刻的字典序最小。先加入当前时刻结束的全部事件再查询，才能计入零时长事件。

**第三步：反转时间轴求另一侧。** 将事件 $[S_i,E_i]$ 映射为 $[-E_i,-S_i]$，费用和收益不变。再次扫描得到原时间轴上“固定进入时刻”的最优区间。这一遍最大值并列时应选更大的反向进入下标，对应原来的更早退出时刻。

**第四步：前后缀分解两次停留。** 正向结果求前缀最优，反向结果还原后求后缀最优。枚举相邻端点之间的分界，左段退出不晚于 $t_c$，右段进入不早于 $t_{c+1}$，自然满足严格不重叠。只合并两段收益都为正的方案，并与所有单段方案比较。

任意合法的两段方案都存在这样的分界；分界固定后，两侧互不影响，分别取最大收益不会变差。收益相同则比较完整的区间元组，Python 的元组字典序也能正确处理“一段是两段方案的前缀”的情形。

### 题解代码

```python
import sys


class SegmentTree:
    def __init__(self, base, prefer_right=False):
        self.n = len(base)
        self.prefer_right = prefer_right
        self.best = [None] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self.build(1, 0, self.n - 1, base)

    def build(self, node, left, right, base):
        if left == right:
            tie = left if self.prefer_right else -left
            self.best[node] = (base[left], tie)
            return
        mid = (left + right) // 2
        self.build(node * 2, left, mid, base)
        self.build(node * 2 + 1, mid + 1, right, base)
        self.best[node] = max(self.best[node * 2], self.best[node * 2 + 1])

    def apply(self, node, value):
        score, tie = self.best[node]
        self.best[node] = (score + value, tie)
        self.lazy[node] += value

    def push(self, node):
        value = self.lazy[node]
        if value:
            self.apply(node * 2, value)
            self.apply(node * 2 + 1, value)
            self.lazy[node] = 0

    def add(self, end, value, node=1, left=0, right=None):
        if right is None:
            right = self.n - 1
        if right <= end:
            self.apply(node, value)
            return
        self.push(node)
        mid = (left + right) // 2
        self.add(end, value, node * 2, left, mid)
        if end > mid:
            self.add(end, value, node * 2 + 1, mid + 1, right)
        self.best[node] = max(self.best[node * 2], self.best[node * 2 + 1])

    def query(self, end, node=1, left=0, right=None):
        if right is None:
            right = self.n - 1
        if right <= end:
            return self.best[node]
        self.push(node)
        mid = (left + right) // 2
        answer = self.query(end, node * 2, left, mid)
        if end > mid:
            answer = max(answer, self.query(end, node * 2 + 1, mid + 1, right))
        return answer


def scan(events, times, cost, prefer_right=False):
    index = {time: i for i, time in enumerate(times)}
    buckets = [[] for _ in times]
    for start, end, value in events:
        buckets[index[end]].append((index[start], value))
    tree = SegmentTree([time * cost for time in times], prefer_right)
    answer = []
    for i, time in enumerate(times):
        for start, value in buckets[i]:
            tree.add(start, value)
        score, tie = tree.query(i)
        start = tie if prefer_right else -tie
        answer.append((score - time * cost, (times[start], time)))
    return answer


def better(a, b):
    if a[0] != b[0]:
        return a if a[0] > b[0] else b
    return a if a[1] < b[1] else b


def optimize(events, cost):
    times = sorted({time for start, end, _ in events for time in (start, end)})
    forward = scan(events, times, cost)
    reverse_events = [(-end, -start, value) for start, end, value in events]
    reverse_times = [-time for time in reversed(times)]
    backward = scan(reverse_events, reverse_times, cost, True)
    backward = [(score, (-end, -start))
                for score, (start, end) in reversed(backward)]
    size = len(times)
    prefix = [None] * size
    suffix = [None] * size
    current = (0, ())
    for i, (score, interval) in enumerate(forward):
        if score > 0:
            current = better(current, (score, (interval,)))
        prefix[i] = current
    current = (0, ())
    for i in range(size - 1, -1, -1):
        score, interval = backward[i]
        if score > 0:
            current = better(current, (score, (interval,)))
        suffix[i] = current
    answer = prefix[-1]
    for i in range(size - 1):
        left, right = prefix[i], suffix[i + 1]
        if left[0] > 0 and right[0] > 0:
            answer = better(answer, (left[0] + right[0], left[1] + right[1]))
    return answer


def solve():
    input = sys.stdin.readline
    n, cost = map(int, input().split())
    events = [tuple(map(int, input().split())) for _ in range(n)]
    score, intervals = optimize(events, cost)
    print(score)
    if not intervals:
        print("NA")
    else:
        for start, end in intervals:
            print(f"{start},{end}")


if __name__ == "__main__":
    solve()
```

### 复杂度分析

**时间复杂度**：$O(N\log N)$。不同端点最多有 $2N$ 个，两次扫描各执行线性次对数级的线段树操作。

**空间复杂度**：$O(N)$，用于端点、事件分桶、线段树及前后缀最优方案。

## 小结

- 字符串删除题必须把注释保护、关键字边界、换行保留分别落实，不能用不带语境的全局替换。
- 拾取道具会改变可通行范围时，应把道具状态纳入 BFS，而不是只记录位置。
- 最多两个不相交区间的优化，可以先求单段最优，再使用前后缀拆分；恢复方案时，线段树内部和最终合并都必须落实字典序规则。
