    71|## 题解：排序 + 严格递增最长上升子序列
    72|### 题目问题拆解
    73|个人同时出发，各自朝目标匀速走一段后停住，要挑出尽可能多的人，使他们在任意时刻两两都不重合。
    74|这是一道判据推导远难于实现的题：代码只有排序加一趟 LIS，难点全在证明"两人会不会相遇"能压缩成一个不等式。
    75|### 算法实现
    76|朴素做法是两两判相遇、把互不相遇的人连边求最大团，但最大团是 NP 难的， 到  时连建图的  都过不去，只能去看穿"不相遇"这个关系本身。
    77|每个人的运动只有一个相位，先以速度  走向目标，到了就永久停下：
    78|速度因此只取 ，且一旦变成  就不再变回去。
    79|看两人的差值 ，它的斜率只在某人停下的瞬间改变。设  先降后升，上升段必在其中一人停下之后：若先停的是 ，该段斜率为 ，而下降段斜率  要求 ；先停的是  则同理要求 。两者都超出速度上限，故  没有内部极小值，最小值必在  或  取到。
    80|由介值定理，相遇当且仅当  在这两端异号或有一端为零，取反即得不相遇的判据：
    81|起点的先后与终点的先后必须一致，且两处都不许并列。这是严格偏序，选出的人两两可比、必构成一条链，故答案等于按  升序排好后终点序列的最长严格递增子序列长度。
    82|起点并列要单独安排： 的两人在  就站在一起，至多留一个。把同组内的终点按降序排，该组终点递减，求严格递增时自然只会选中一个，不必另写去重。
    83|求 LIS 用  数组， 存长度  的递增子序列中最小的结尾值，每个终点用 `bisect_left` 替换第一个不小于它的位置，越界则追加。不能换成 `bisect_right`：等值被替换掉才是严格递增，否则终点相同的两人会被一起选进来，而他们最终停在同一点上。
    84|### 时空复杂度分析
    85|**时间复杂度** ：，瓶颈是排序与 LIS 两趟， 时约  次比较。把相遇判定从两两比较换成一次排序，正是绕开  建图的关键。
    86|**空间复杂度** ：，存下  数组与 。
    87|**Python**
    88|
    89|```
    90|# 最多不相遇人数 - 排序 + 严格递增最长上升子序列
    91|from bisect import bisect_left
    92|
    93|def order_by_start(p, q):
    94|    """第一步：把 n 个人按起点排队，返回排好队之后的终点序列"""
    95|    people = list(zip(p, q))
    96|    # 起点相同的两人在 t = 0 就站在一起，必定相遇；让他们的终点降序排列，
    97|    # 后面求"严格递增"时同一起点里最多只能选中一个，不用再额外判重
    98|    people.sort(key=lambda person: (person[0], -person[1]))
    99|    return [end for _, end in people]
   100|
   101|def strict_lis(ends):
   102|    """第二步：求终点序列的最长严格递增子序列长度，即能选出的最多人数"""
   103|    # tails[k] 存放长度为 k+1 的递增子序列中最小的那个结尾值，整体单调递增
   104|    tails = []
   105|    for end in ends:
   106|        # bisect_left 找第一个 >= end 的位置，等值也会被替换掉，得到的才是严格递增
   107|        pos = bisect_left(tails, end)
   108|        if pos == len(tails):
   109|            tails.append(end)
   110|        else:
   111|            tails[pos] = end
   112|    return len(tails)
   113|
   114|t = int(input())
   115|for _ in range(t):
   116|    n = int(input())
   117|    p = list(map(int, input().split()))
   118|    q = list(map(int, input().split()))
   119|    # 两人永不相遇 <=> 起点的先后与终点的先后一致，
   120|    # 于是"任意两人都不相遇的最大人群"就是起点、终点同时严格递增的最长链
   121|    print(strict_lis(order_by_start(p, q)))
   122|```

   168|## 题解：全批梯度下降训练 Logistic Regression
   169|### 题目问题拆解
   170|按题面写死的口径训练一个带偏置的二分类逻辑回归，再用  把测试集映射成  标签。
   171|这是一道口径复刻型的 ML 题：算法本身是教科书里的逻辑回归，难点不在想法，而在把学习率、轮数、bias 拼接位置、clip 范围、判定阈值五处口径一字不差地照搬，任一处偏了预测就整片翻转。
   172|### 算法实现
   173|**特征增广** ：每条特征最左侧拼一列常数 ，得 ，训练矩阵维度由  变成 。偏置于是并进权向量  一起更新，不必单独维护。
   174|**Sigmoid 与数值稳定性** ：
   175|截断不是可选项： 小于  时  会溢出成 inf。而  与  相差不到 ，改不动  的判定，属于只挡溢出、不动语义的处理。
   176|**梯度与更新** ：交叉熵损失对  求导后化简得
   177|残差  是每条样本的预测误差，左乘  把它按特征方向摊回各维权重，除以  取全体样本的平均。 意味着正则项恒为零，梯度里不再补 。
   178|**为什么能整批向量化** ：同一轮里所有样本共用同一个 ，彼此没有先后依赖，一轮因此能压成两次矩阵乘法；感知机那类在线更新则因第  条会改变第  条的预测而只能串行。
   179|**维度变化** ：前向 ；回传 ；预测 。
   180|权重初值全零、不引入随机数，固定跑满  轮，线性不可分时不收敛也照跑，结果才可复现。输出前须把布尔数组转成整型，否则 JSON 打印出的是 true 与 false，而非题面要求的 。
   181|### 时空复杂度分析
   182|**时间复杂度** ：训练 ， 轮、每轮两次  规模的矩阵乘法；预测 。瓶颈在轮数， 是题面钉死的省不掉，但每轮已压成 BLAS 矩阵乘法， 且  时总量不足 。
   183|**空间复杂度** ：，增广后的训练矩阵与测试矩阵。
   184|**Python**
   185|
   186|```
   187|# 逻辑回归二分类 - 全批梯度下降训练 Logistic Regression
   188|import json
   189|
   190|import numpy as np
   191|
   192|# 这三个都是题面写死的工艺参数，不是要自己调的超参：固定跑满 800 轮，不看是否收敛
   193|LR = 0.2
   194|EPOCHS = 800
   195|CLIP = 30.0  # sigmoid 入参的截断范围
   196|
   197|def sigmoid(z):
   198|    """σ(z) = 1 / (1 + e^{-z})。先把 z 截到 [-30, 30] 再算：
   199|    z 稍大一点 e^{-z} 就会溢出成 inf 并打出 RuntimeWarning，
   200|    而截断只影响概率的第 14 位小数，不改变 p >= 0.5 的判定结果。"""
   201|    z = np.clip(z, -CLIP, CLIP)
   202|    return 1.0 / (1.0 + np.exp(-z))
   203|
   204|# ---- 第一步：读入并整理数据 ----
   205|# 输入是单行 JSON，读一行直接解析
   206|data = json.loads(input())
   207|train = data["train"]
   208|test = data["test"]
   209|
   210|# 训练集每行的格式是"d 个特征 + 最后一列标签"，整体读成矩阵后按列切开
   211|train_mat = np.asarray(train, dtype=np.float64)  # (n, d+1)
   212|train_x = train_mat[:, :-1]                      # (n, d) 特征矩阵
   213|train_y = train_mat[:, -1]                       # (n,)   标签，取值 0/1
   214|
   215|n = train_x.shape[0]
   216|# 每条特征最左侧拼一列常数 1 当 bias，偏置就并进权向量一起更新，不必单独维护
   217|train_v = np.hstack([np.ones((n, 1)), train_x])  # (n, 1) 拼 (n, d) -> (n, d+1)
   218|
   219|w = np.zeros(train_v.shape[1])  # 权重全 0 起步，题面规定不做随机初始化
   220|
   221|# ---- 第二步：全批梯度下降训练 ----
   222|# "全批"的含义是每轮都拿全部 n 条样本算一次平均梯度、再统一走一步。
   223|# 同一轮里所有样本用的是同一个 w，彼此没有先后依赖，所以能整批矩阵运算，
   224|# 不像感知机那种在线更新必须逐条扫
   225|for _ in range(EPOCHS):
   226|    p = sigmoid(train_v @ w)              # (n, d+1) @ (d+1,) -> (n,) 当前预测概率
   227|    # 交叉熵损失对 w 的梯度恰好化简成 X̄ᵀ(p - y)/n，(p - y) 就是每条样本的预测误差
   228|    grad = train_v.T @ (p - train_y) / n  # (d+1, n) @ (n,) -> (d+1,)
   229|    # 题面固定 l2 = 0.0，正则项恒为 0，所以梯度里不再额外加 l2 * w
   230|    w -= LR * grad
   231|
   232|# ---- 第三步：预测 ----
   233|# 训练结束权重就固定了，各测试样本互不影响，一次矩阵乘法批量算完
   234|test_x = np.asarray(test, dtype=np.float64)                  # (m, d)
   235|test_v = np.hstack([np.ones((test_x.shape[0], 1)), test_x])  # (m, d+1)
   236|prob = sigmoid(test_v @ w)                                   # (m,)
   237|
   238|# 概率 >= 0.5 判正类 1、否则判 0；先转成 int64 再 tolist()，
   239|# 否则 bool 数组会让 json 打印出 true/false 而不是题面要求的 0/1
   240|result = (prob >= 0.5).astype(np.int64)
   241|
   242|print(json.dumps(result.tolist()))
   243|```
