    86|## 题解：排序 + 严格最长上升子序列
    87|### 题目问题拆解
    88|每个人从  匀速走向 ，到了就停下。要选出最多的人，使任意两人在任意时刻都不站在同一位置。
    89|这是一道判定条件比算法更难的题：难点在于把"两人永不相遇"这个含时间的性质，翻译成只跟 、 有关的静态条件。
    90|### 算法实现
    91|先把时间从相遇里剥出来。记位置差 ，两条轨迹连续， 也连续，且
    92|两值异号时由介值定理 中途必取到 ，两人一定相遇；某个值为  则起点重合（ 就撞上）或终点重合，同样相遇。所以不相遇必须有 。
    93|它也是充分的，靠的是每个人只朝一个方向走。设  而两人在  点相遇， 是从左边追上来的，追上那一刻  必在向右走， 要么向左走要么已停住；轨迹单调，此后  不会回到  左侧、 不会回到  右侧，得 ，与  矛盾。
    94|于是条件化成起点顺序与终点顺序一致。把人按  升序排队，被选中者的  必须严格递增，答案即  的严格最长上升子序列长度。 相同的两人在  已经相遇，排序时令这一组内部  降序，组内就凑不出上升对，至多选走一个，不必特判。
    95|朴素的  逐对转移在  下要做  次比较，必然超时。改用  数组，记
    96|的取值是某条长度为的严格上升链的结尾
    97|它随  天然递增，每个  二分找第一个不小于它的位置替换，越界则接在末尾。二分取 `bisect_left` 而非 `bisect_right`，等值也被替换，保证的才是严格递增。
    98|### 时空复杂度分析
    99|**时间复杂度** ：。瓶颈是排序，其后每人只做一次  的二分； 为  时总量在千万级以内。
   100|**空间复杂度** ：，排序后的数对与  数组各一份。
   101|**Java**
   102|
   103|```
   104|// 不相遇的最多人数 - 排序 + 严格最长上升子序列
   105|import java.io.BufferedReader;
   106|import java.io.InputStreamReader;
   107|import java.io.PrintWriter;
   108|import java.io.StreamTokenizer;
   109|import java.util.Arrays;
   110|
   111|public class Main {
   112|    // 求最多能选出多少人两两永不相遇
   113|    static int maxNonMeeting(int[][] people) {
   114|        // 两人永不相遇要求起点不同、终点不同，且起点的先后顺序与终点的先后顺序一致，
   115|        // 所以被选中的人按起点排好队后，终点也必须严格递增。
   116|        // 起点升序、起点相同时终点降序，这样同一个起点上最多只会被选走一个人
   117|        Arrays.sort(people, (a, b) -> {
   118|            if (a[0] != b[0]) {
   119|                return Integer.compare(a[0], b[0]);
   120|            }
   121|            return Integer.compare(b[1], a[1]);
   122|        });
   123|        // tails[k]: 长度为 k+1 的上升链，结尾终点能取到的最小值；len 是已用长度
   124|        int[] tails = new int[people.length];
   125|        int len = 0;
   126|        for (int[] person : people) {
   127|            int q = person[1];
   128|            // 二分找第一个不小于 q 的位置：等值也要被替换掉，才能保证严格上升
   129|            int lo = 0;
   130|            int hi = len;
   131|            while (lo < hi) {
   132|                int mid = (lo + hi) >>> 1;
   133|                if (tails[mid] < q) {
   134|                    lo = mid + 1;
   135|                } else {
   136|                    hi = mid;
   137|                }
   138|            }
   139|            // 落在末尾说明比所有链尾都大，链长加一；否则用更小的结尾替换，给后面留空间
   140|            tails[lo] = q;
   141|            if (lo == len) {
   142|                len++;
   143|            }
   144|        }
   145|        return len;
   146|    }
   147|
   148|    public static void main(String[] args) throws Exception {
   149|        // 数据量大，用 StreamTokenizer 按空白切词读入，输出走带缓冲的 PrintWriter
   150|        StreamTokenizer in = new StreamTokenizer(new BufferedReader(new InputStreamReader(System.in)));
   151|        PrintWriter out = new PrintWriter(System.out);
   152|        in.nextToken();
   153|        int t = (int) in.nval;
   154|        // 多组测试：每组三行（人数、起点、终点），算完一组就直接输出这一组的答案
   155|        while (t-- > 0) {
   156|            in.nextToken();
   157|            int n = (int) in.nval;
   158|            int[][] people = new int[n][2];
   159|            // 起点和终点分两行给出，先读完全部起点，再回填各人的终点
   160|            for (int i = 0; i < n; i++) {
   161|                in.nextToken();
   162|                people[i][0] = (int) in.nval;
   163|            }
   164|            for (int i = 0; i < n; i++) {
   165|                in.nextToken();
   166|                people[i][1] = (int) in.nval;
   167|            }
   168|            out.println(maxNonMeeting(people));
   169|        }
   170|        out.flush();
   171|    }
   172|}
   173|```

   230|## 题解：切比雪夫转化
   231|### 题目问题拆解
   232|在  行  列的地图上挑两块不同的空地，使两者的曼哈顿距离最大，输出任意一组。
   233|这是一道靠换坐标把二维问题拆成两个一维问题的题：两两枚举空地是 ， 达  时最坏要跑  次，必须先把那两个绝对值解开。
   234|### 算法实现
   235|难点在于  里两个绝对值互相牵制，谁也定不下来。记 、，恒有 ：两数同号时  取到 、 更小，异号时两者互换角色。
   236|而  与  各自只跟一个新坐标有关。令
   237|就有 、，于是两点的曼哈顿距离等于它们在  轴与  轴上距离的较大者。两个维度就此解耦，最大距离是
   238|这个上界能取到。取  最大与  最小的那两块空地，它们的  差恰为 ，故曼哈顿距离不小于该值；又不可能超过全局最大值，两头一夹即相等，直接输出这一对。 侧同理，哪侧极差大就输出哪侧。
   239|扫描还能再省一层。同一行里  随  递增、 随  递减，所以每行只有最左和最右两块空地够得着这四个极值，用 `find` 与 `rfind` 各定位一次即可，整行不必逐格判断。
   240|两点必然互异：题面保证每组至少有两块空地，若两个极差同时为 ，则所有空地的  与  都相同，而  唯一确定 ，等于说只有一块空地，与保证矛盾。
   241|### 时空复杂度分析
   242|**时间复杂度** ：。瓶颈是读入整张地图，扫描阶段每行只做两次定位， 为  时总量在百万级以内。
   243|**空间复杂度** ：，存下当前这组地图；极值本身只占常数个变量。
   244|**Java**
   245|
   246|```
   247|// 曼哈顿距离最大的两块空地 - 切比雪夫转化
   248|import java.io.BufferedReader;
   249|import java.io.InputStreamReader;
   250|import java.io.PrintWriter;
   251|
   252|public class Main {
   253|    // 求出一组曼哈顿距离最大的空地，返回 {r1, c1, r2, c2}，行列均从 1 开始
   254|    static int[] solveGrid(int n, String[] rows) {
   255|        // |r1-r2|+|c1-c2| 等于 |u1-u2| 与 |v1-v2| 中的较大者（u=r+c，v=r-c），
   256|        // 所以最大距离就是 u 的极差与 v 的极差里更大的那个，只需记住四个极值点
   257|        int maxU = Integer.MIN_VALUE, minU = Integer.MAX_VALUE;
   258|        int maxV = Integer.MIN_VALUE, minV = Integer.MAX_VALUE;
   259|        int[] pMaxU = null, pMinU = null, pMaxV = null, pMinV = null;
   260|        for (int i = 0; i < n; i++) {
   261|            int first = rows[i].indexOf('.');
   262|            // 整行都是障碍物，对四个极值都没有贡献
   263|            if (first < 0) {
   264|                continue;
   265|            }
   266|            int last = rows[i].lastIndexOf('.');
   267|            int r = i + 1;
   268|            // 同一行里 u=r+c 随 c 递增、v=r-c 随 c 递减，
   269|            // 所以本行只有最左和最右两块空地可能成为极值点，不必逐格扫
   270|            int cl = first + 1;
   271|            int cr = last + 1;
   272|            if (r + cr > maxU) {
   273|                maxU = r + cr;
   274|                pMaxU = new int[]{r, cr};
   275|            }
   276|            if (r + cl < minU) {
   277|                minU = r + cl;
   278|                pMinU = new int[]{r, cl};
   279|            }
   280|            if (r - cl > maxV) {
   281|                maxV = r - cl;
   282|                pMaxV = new int[]{r, cl};
   283|            }
   284|            if (r - cr < minV) {
   285|                minV = r - cr;
   286|                pMinV = new int[]{r, cr};
   287|            }
   288|        }
   289|        // 取极差更大的那一侧：这两点的真实曼哈顿距离恰好等于该极差，故必为最优
   290|        boolean useU = maxU - minU >= maxV - minV;
   291|        int[] a = useU ? pMinU : pMinV;
   292|        int[] b = useU ? pMaxU : pMaxV;
   293|        return new int[]{a[0], a[1], b[0], b[1]};
   294|    }
   295|
   296|    public static void main(String[] args) throws Exception {
   297|        // 行长可达 2*10^5，用带缓冲的读入按整行取，避免逐字符的系统调用
   298|        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
   299|        PrintWriter out = new PrintWriter(System.out);
   300|        int t = Integer.parseInt(br.readLine().trim());
   301|        while (t-- > 0) {
   302|            // 这一行是 n 和 m，列数 m 用不上：每行字符串自带长度
   303|            String[] head = br.readLine().trim().split("\\s+");
   304|            int n = Integer.parseInt(head[0]);
   305|            String[] rows = new String[n];
   306|            for (int i = 0; i < n; i++) {
   307|                rows[i] = br.readLine().trim();
   308|            }
   309|            int[] res = solveGrid(n, rows);
   310|            out.println(res[0] + " " + res[1] + " " + res[2] + " " + res[3]);
   311|        }
   312|        // T 可达 2*10^5，逐行裸输出会真 TLE，最后统一刷缓冲
   313|        out.flush();
   314|    }
   315|}
   316|```
