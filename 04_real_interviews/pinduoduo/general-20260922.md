## 第 1 题：货架最少搬运次数

### 题目描述

仓库有 $N$ 个位置固定的货架，第 $i$ 个货架上有 $A_i$ 件商品。一次搬运可以选择连续区间 $[l,r]$，但该区间内所有货架的商品数量必须完全相同；操作会搬走这些货架上的全部商品。

例如，连续的 `2 2 2` 可以一次搬空，`2 3 2` 不可以。搬空的货架仍留在原位，商品数变为零，并不会删除位置或让两侧货架拼接。求清空所有货架的最少操作次数。

### 输入描述

第一行是测试组数 $T$，满足 $1\le T\le 10$。每组先输入 $N$，再输入 $N$ 个整数 $A_i$，满足 $1\le N\le 10^5$、$1\le A_i\le 10^5$。

### 输出描述

每组输出一个整数，表示最少搬运次数。

### 样例 1

**输入**

```
1
8
2 2 3 3 3 1 1 2
```

**输出**

```
4
```

四段分别为 `2 2`、`3 3 3`、`1 1`、`2`，每段搬运一次。

### 思路分析

**第一步：按相邻元素是否相等分段。** 连续且取值相同、不能再向两侧扩展的区间称为极大等值段。扫描时，第一个元素开启第一段；此后每遇到一个与左邻不同的值，就开启新的一段。

**第二步：证明段数是下界。** 搬运不会改变未清空货架上的正数，只会把某些位置变为零。原本不同的正数不能一起搬；原本相等但分属不同段的正数，也始终被其他正数或已清空的零隔开。因此一次有效搬运不可能同时清空两个原始等值段中的商品。

**第三步：达到下界。** 对每个原始等值段单独操作一次，就能清空所有货架。由下界和构造可知，答案恰好是段数，而不是不同商品数量的个数。

### 题解代码

```python
import sys
input = sys.stdin.readline


def count_moves(values):
    return 1 + sum(values[i] != values[i - 1]
                   for i in range(1, len(values)))


def solve():
    t = int(input())
    answers = []
    for _ in range(t):
        n = int(input())
        values = []
        while len(values) < n:
            values.extend(map(int, input().split()))
        answers.append(str(count_moves(values)))
    print('\n'.join(answers))


if __name__ == '__main__':
    solve()
```

### 复杂度分析

**时间复杂度**：每组 $O(N)$，只需比较相邻元素。

**空间复杂度**：$O(N+T)$，保存当前数组和各组输出。

## 第 2 题：多多字符串

### 题目描述

给定一个只包含 `a`、`b` 的非空字符串。可以删除任意多个字符，但不能改变保留字符的先后顺序。

目标字符串需要能分成连续三段：第一段只含 `a`，第二段只含 `b`，第三段只含 `a`，任意一段都可以为空。求能够得到的最长目标字符串长度。

### 输入描述

输入字符串 $s$，满足 $1\le \lvert s\rvert\le 5000$，且只包含小写字母 `a` 和 `b`。

### 输出描述

输出最长多多字符串的长度。

### 样例 1

**输入**

```
abba
```

**输出**

```
4
```

`abba` 已经符合 `a`、`bb`、`a` 的三段结构。

### 样例 2

**输入**

```
bab
```

**输出**

```
2
```

删除首尾任意一个 `b`，得到 `ab` 或 `ba`；保留全部字符则不符合要求。

### 思路分析

**第一步：用阶段代替具体子序列。** 枚举删除方案需要指数级搜索，但目标形态只有三个阶段。定义 `first` 为只使用第一段 `a` 的最优长度，`middle` 为形如“前段 a、中段 b”的最优长度，`last` 为完整三段形态的最优长度。各段允许为空，因此三个状态初始均为零。

**第二步：区分当前字符。** 如果当前字符是 `a`，第一段可以延长；中段不能接入这个字符，直接保留原状态；第三段既可以延续，也可以从中段切换过来。若字符是 `b`，只有中段能接入，来源可以是第一段或已经开始的中段。

具体转移中，遇到 `a` 时先计算 `last = max(last, middle) + 1`，再增加 `first`；遇到 `b` 时令 `middle = max(first, middle) + 1`。不适合当前阶段的字符可以删除，所以其余状态不变。中段为空的全 `a` 方案由 `first` 覆盖，不需要强行跨过两个阶段。

**第三步：取所有结束阶段的最大值。** 目标不要求三段都出现，因此不能只取最后一段状态。

### 正确性证明

对已处理前缀归纳。最优方案若不保留当前字符，继承相应旧状态即可；若保留，则该字符必须匹配所在段，只能延续本段或从允许的前一段转入。上述转移覆盖这些情况，且不会改变阶段顺序。对于可以延长的状态，加入一个合法字符总不劣于删除它。最后对三个状态取最大值，覆盖全部合法结束位置。

### 题解代码

```python
import sys
input = sys.stdin.readline


def longest_duoduo(s):
    first = middle = last = 0
    for char in s:
        if char == 'a':
            last = max(last, middle) + 1
            first += 1
        else:
            middle = max(first, middle) + 1
    return max(first, middle, last)


def solve():
    print(longest_duoduo(input().strip()))


if __name__ == '__main__':
    solve()
```

### 复杂度分析

**时间复杂度**：$O(n)$，其中 $n=\lvert s\rvert$，每个字符进行常数次更新。

**空间复杂度**：$O(n)$，用于保存输入字符串；动态规划仅需常数个额外状态。

## 第 3 题：果园最小收集边长

### 题目描述

果园是由边长为 1 的正方形单元格组成的二维网格。共有 $n$ 个苹果，各自在不同的单元格中，用整数坐标 $(x_i,y_i)$ 表示。

收集器可以选择一个由 $m^2$ 个完整单元格组成、与网格轴对齐的正方形区域，一次收走其中所有苹果。为了至少收集 $c$ 个苹果，求正方形的最小整数边长 $m$。

### 输入描述

第一行输入 $n,c$，满足 $1\le c\le n\le 10^3$。

接下来 $n$ 行，每行输入 $x_i,y_i$，满足 $1\le x_i,y_i\le 10^9$，所有位置两两不同。部分测试数据的坐标不超过 1000。

### 输出描述

输出至少覆盖 $c$ 个苹果所需的最小边长。

### 样例 1

**输入**

```
10 3
47 66
33 81
30 90
27 86
30 76
49 47
55 76
12 76
11 98
19 59
```

**输出**

```
10
```

横坐标覆盖 `27..36`、纵坐标覆盖 `81..90` 时，可以收集 `(33,81)`、`(30,90)`、`(27,86)`。

### 样例 2

**输入**

```
15 15
64 81
17 55
58 5
51 8
26 31
42 61
79 97
98 50
68 42
55 57
26 87
83 67
25 52
53 26
83 61
```

**输出**

```
93
```

需要覆盖所有苹果，纵坐标范围为 `5..97`，横坐标范围为 `17..98`。覆盖完整单元格时，跨度需分别加一，边长取两者最大值。

### 思路分析

**第一步：把左边界限制到苹果横坐标。** 任意可行区域都可以向右平移，直到左边界贴住区域内最靠左的苹果。这个过程中左边不会越过已包含的苹果，右边界则向外扩展，原来的苹果不会丢失。因此只需枚举至多 $n$ 个不同横坐标。

**第二步：固定左边界，线性判定一个边长。** 预先按纵坐标排序。给定左边界 `left` 和边长 `side`，筛出满足 `left <= x < left + side` 的点，得到仍然有序的纵坐标数组 `ys`。

纵向存在可行位置，当且仅当某个连续 $c$ 元素窗口满足：

$$
ys[i+c-1]-ys[i]<side.
$$

这是完整网格的关键：相差 `side` 的两个单元格不能装进 `side` 格，而相差 `side - 1` 可以。若某个纵向区间包含至少 $c$ 个点，其中必然存在连续的 $c$ 个点也被包含；反之，一个跨度合格的窗口可以直接构造区域。两个端点同步向右移动即可完成检查。

**第三步：利用单调性二分，并先做改进试探。** 固定左边界时，边长越大越容易可行。设当前全局可行上界为 `best`，先检查 `best - 1`。若失败，该左边界不可能改进答案，直接跳过；若成功，才在 `[1,best - 1]` 内二分。注意全局可行上界并不一定对每个左边界都可行，不能不经试探就把它当作该边界的二分上界。

初始 `best` 取全部苹果包围盒的最大跨度加一。这已经是一个可行解；若最后无人改善，直接返回也正确。

**第四步：随机化候选顺序。** 每个候选有固定的最小可行边长，不可行时可视为无穷大。随机排列候选后，第 $k$ 个候选严格刷新最优值的概率至多为 $1/k$，所以真正进入二分的次数期望为 $O(\log n)$。随机性仅影响速度，不影响答案；当 `best == 1` 时可以立即结束。不能把这一期望界写成最坏界。

### 正确性证明

候选边界压缩保留了至少一个最优解的位置。对固定候选，横向筛选恰好留下可能进入区域的点，纵向窗口条件又与至少覆盖 $c$ 点等价，因此判定正确。单调性保证二分返回该候选的最小边长；试探失败只排除不能严格改善现有答案的候选。初始答案可行，整个过程只用可行值改进，处理完所有候选后得到全局最优值。

### 题解代码

```python
import sys
import random
input = sys.stdin.readline


def can_cover(by_y, target, left, side):
    ys = [y for x, y in by_y if left <= x < left + side]
    for i in range(len(ys) - target + 1):
        if ys[i + target - 1] - ys[i] < side:
            return True
    return False


def minimum_side(points, target):
    by_y = sorted(points, key=lambda point: point[1])
    xs = [x for x, _ in points]
    ys = [y for _, y in points]
    best = max(max(xs) - min(xs), max(ys) - min(ys)) + 1
    lefts = list(set(xs))
    random.shuffle(lefts)
    for left in lefts:
        if best == 1:
            break
        if not can_cover(by_y, target, left, best - 1):
            continue
        lo, hi = 1, best - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if can_cover(by_y, target, left, mid):
                hi = mid
            else:
                lo = mid + 1
        best = lo
    return best


def solve():
    n, target = map(int, input().split())
    points = [tuple(map(int, input().split())) for _ in range(n)]
    print(minimum_side(points, target))


if __name__ == '__main__':
    solve()
```

### 复杂度分析

**时间复杂度**：期望 $O(n^2+n\log n\log V)$，最坏 $O(n^2\log V)$，其中 $V=10^9$。每个候选的试探花费 $O(n)$，只有刷新最优值的候选继续二分；预排序花费 $O(n\log n)$。

**空间复杂度**：$O(n)$，用于坐标、排序结果、候选边界和判定窗口。

## 第 4 题：括号串翻转与合法查询

### 题目描述

给定长度为 $n$ 的括号串 $s$，只包含 `(` 和 `)`。按顺序执行 $q$ 个操作：

- `F l r`：把闭区间 $[l,r]$ 内的每个左括号改为右括号、右括号改为左括号。这里是**括号类型取反，不是字符顺序倒置**。
- `Q l r`：判断当前子串 $s[l\ldots r]$ 是否为合法括号序列，即能否正确匹配所有括号。

下标从 1 开始。例如 `(()())` 执行 `F 2 5` 后变成 `()()()`。

### 输入描述

第一行输入 $n,q$，满足 $1\le n,q\le 200000$。第二行输入长度为 $n$ 的括号串。

之后 $q$ 行，每行输入一条 `F l r` 或 `Q l r`，保证 $1\le l\le r\le n$。

### 输出描述

对每个查询，合法时输出 `YES`，否则输出 `NO`。翻转操作不输出结果。

### 样例 1

**输入**

```
6 5
(()())
Q 1 6
F 2 5
Q 1 6
F 3 4
Q 1 6
```

**输出**

```
YES
YES
NO
```

第一次翻转后为 `()()()`，仍合法；第二次翻转后为 `())(()`，扫描到第三个字符时已经无法匹配。

### 思路分析

**第一步：把合法性变为前缀条件。** 令左括号贡献 $+1$，右括号贡献 $-1$。括号串合法，当且仅当总和为零，且任意前缀和都非负。这里必须以查询子串的起点重新计算前缀，不能使用原串前缀值直接判断。

**第二步：维护能拼接的区间摘要。** 每个节点维护区间和 `total`、最小前缀 `low`、最大前缀 `high`，把空前缀也包含在内。左右区间合并时，右侧的前缀需要先加上左侧总和：

$$
\begin{aligned}
S &= S_L+S_R,\\
L &= \min(L_L,S_L+L_R),\\
H &= \max(H_L,S_L+H_R).
\end{aligned}
$$

叶子值为 $v$ 时，摘要就是 $(v,\min(0,v),\max(0,v))$。

**第三步：推导整段翻转。** 类型取反后，每个前缀和都变为原来的相反数。因此摘要更新为：

$$
(S,L,H)\longrightarrow(-S,-H,-L).
$$

这解释了为何仅维护最小前缀不够：翻转后的最小值依赖翻转前的最大值。懒标记使用异或，同一区间连续翻转两次即恢复原状。部分覆盖时先下传标记，修改结束再重新合并。

**第四步：按原顺序查询。** 拼接操作不满足交换律，查询必须先左后右。用 `(0,0,0)` 表示空区间，它是摘要合并的单位元。最终摘要满足总和为零且最小前缀非负时输出 `YES`。奇数长度可以直接判为 `NO`。

### 正确性证明

叶子的三个统计量直接符合定义。若两子节点摘要正确，合并公式枚举了所有位于左侧的前缀，以及完整左侧加右侧前缀，因此父节点摘要正确。翻转公式逐一取反全部前缀，正确交换其最大最小值；懒标记异或准确记录尚未下传的翻转奇偶性。由建树、更新和查询的递归过程归纳，查询得到的始终是目标子串的真实摘要，再由前缀和合法性条件即可得到正确回答。

### 题解代码

```python
import sys
input = sys.stdin.readline


def merge(left, right):
    return (left[0] + right[0],
            min(left[1], left[0] + right[1]),
            max(left[2], left[0] + right[2]))


class BracketTree:
    def __init__(self, s):
        self.n = len(s)
        self.info = [(0, 0, 0)] * (4 * self.n)
        self.lazy = [False] * (4 * self.n)
        self.build(1, 1, self.n, s)

    def build(self, node, left, right, s):
        if left == right:
            value = 1 if s[left - 1] == '(' else -1
            self.info[node] = (value, min(0, value), max(0, value))
            return
        mid = (left + right) // 2
        self.build(node * 2, left, mid, s)
        self.build(node * 2 + 1, mid + 1, right, s)
        self.pull(node)

    def pull(self, node):
        self.info[node] = merge(self.info[node * 2],
                                self.info[node * 2 + 1])

    def apply(self, node):
        total, low, high = self.info[node]
        self.info[node] = (-total, -high, -low)
        self.lazy[node] = not self.lazy[node]

    def push(self, node):
        if self.lazy[node]:
            self.apply(node * 2)
            self.apply(node * 2 + 1)
            self.lazy[node] = False

    def flip(self, node, left, right, ql, qr):
        if ql <= left and right <= qr:
            self.apply(node)
            return
        self.push(node)
        mid = (left + right) // 2
        if ql <= mid:
            self.flip(node * 2, left, mid, ql, qr)
        if qr > mid:
            self.flip(node * 2 + 1, mid + 1, right, ql, qr)
        self.pull(node)

    def query(self, node, left, right, ql, qr):
        if ql <= left and right <= qr:
            return self.info[node]
        self.push(node)
        mid = (left + right) // 2
        answer = (0, 0, 0)
        if ql <= mid:
            answer = self.query(node * 2, left, mid, ql, qr)
        if qr > mid:
            answer = merge(answer, self.query(node * 2 + 1,
                                              mid + 1, right, ql, qr))
        return answer


def solve():
    n, q = map(int, input().split())
    tree = BracketTree(input().strip())
    answers = []
    for _ in range(q):
        op, left, right = input().split()
        left, right = int(left), int(right)
        if op == 'F':
            tree.flip(1, 1, n, left, right)
        elif (right - left + 1) % 2:
            answers.append('NO')
        else:
            total, low, _ = tree.query(1, 1, n, left, right)
            answers.append('YES' if total == 0 and low >= 0 else 'NO')
    sys.stdout.write('\n'.join(answers))


if __name__ == '__main__':
    solve()
```

### 复杂度分析

**时间复杂度**：$O(n+q\log n)$，建树线性，每次区间翻转或查询为 $O(\log n)$。

**空间复杂度**：$O(n+q)$，树和标记占 $O(n)$，递归栈占 $O(\log n)$，批量输出缓存最多占 $O(q)$。

## 小结
