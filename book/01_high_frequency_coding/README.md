## 单题题解标准

每道题根据题目特点提供多种有价值的解法，并呈现从直观思路到面试推荐解法的演进：

1. 题目与考点
2. 思路推导
3. 解法一：直观或基础解法
4. 解法二：优化解法
5. 其他值得掌握的解法
6. 正确性与复杂度分析
7. 边界用例和常见错误
8. 面试讲解方式与常见追问

不为了凑数量强行添加没有教学价值的解法。使用哈希表时，要明确它减少了哪些重复查找、付出了多少空间，以及是否真正改善复杂度。

- Python 代码以 3.8+ 为兼容基线，不使用 `list[int]`、`X | None` 等更高版本才支持的运行时类型写法。
- 每个代码块必须包含自身所需的导入，不依赖同一篇文档中更早出现的代码块。

## 双指针与哈希表重点

两数之和与三数之和是双指针、哈希表及去重逻辑的重点对照题，必须覆盖两类方法：

- 两数之和：一次遍历哈希表为面试首选；排序加双指针作为对照，并处理返回原下标的问题。
- 三数之和：排序加双指针为面试首选；枚举加哈希表作为替代方案，重点比较空间代价与去重难度。

滑动窗口题应特别关注哈希表优化。例如无重复字符的最长子串，需要比较集合逐步收缩与最近位置哈希表直接移动左边界的区别。

## 题解条目格式

分类文档中的每道正式题解使用以下结构：

```markdown
## LC 题号 题目名称

### 考频与考点
### 写代码前如何确认题意
### 解法一：基础解法
### 解法二：面试推荐解法
### 解法三：其他高价值解法
### 正确性说明
### 复杂度对比
### 边界用例与常见错误
### 面试追问
```

没有教学价值的解法可以省略，但必须说明最终推荐哪种写法及原因。
