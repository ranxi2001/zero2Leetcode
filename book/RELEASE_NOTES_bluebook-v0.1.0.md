# zero2Leetcode 蓝皮书 v0.1.0

首个蓝皮书发行版，包含面试高频手撕、八股文、大厂笔试真题，以及语法、数据结构、测评和 AI Coding 技巧。

## 下载内容

- `zero2Leetcode-蓝皮书-算法面试通关指南.pdf`：完整版本，共 1,392 页。
- `zero2Leetcode-蓝皮书-高频手撕.pdf`：第一章单独发行版，共 92 页。

## 本版内容

- 高频手撕以字节跳动题单的六大分类为主线，共维护 118 道去重题；其他公司统计用于优先级参考和新增题补充。
- 高频题解覆盖考点、题意确认、推荐代码、复杂度、边界条件和面试追问；两数之和、三数之和等题重点比较哈希表与双指针。
- 八股文和大厂笔试真题由编译脚本直接读取网站原始资料，不在 `book/` 中维护副本。
- 新增 Pandoc + XeLaTeX 出版链路，支持指定章节预览、Jekyll include 展开、公式边界检查和特殊字符检查。
- 新封面使用算法数组、哈希表、链表、二叉树、栈、队列和双指针等视觉元素。

## 验证

- 全书构建解析 193 个来源文件、5,003 个标题、10,047 个公式和 1,782 个代码块。
- 第一章 128 个 Python 代码块通过 Python 3.8 语法解析与隔离加载检查，核心题完成定向样例和边界测试。
- 最终 PDF 构建日志为 0 缺字、0 LaTeX 错误、0 Pandoc 警告。
- 已渲染检查封面、版权页、四章首页、代码页、表格页和封底。
